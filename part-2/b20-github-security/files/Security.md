# Security Policy

## Supported Versions
This project is actively maintained. Security updates apply to the latest version only.

## Reporting a Vulnerability
If you discover a security issue, please contact:
justin.roy220304@gmail.com

Do not open a public issue for security vulnerabilities.

## Response Timeline
- Acknowledgement: within 48 hours
- Initial assessment: within 5–7 days
- Fix or mitigation: depends on severity

## Scope
This repository includes coursework and personal projects. Automated dependency scanning and basic security hygiene are applied.
